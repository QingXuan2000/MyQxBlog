如果你最近开始关注 AI Agent，可能听说过 DeepSeek Harness（简称 DSH）。

DSH 是 DeepSeek 推出的开源 Agent 框架。它可以通过模型和插件调用工具，帮助用户完成文件处理、代码编写、终端操作等任务。

官方 DSH 已经提供桌面客户端。不过，官方桌面版目前的桌面管理和生态扩展能力还有进一步完善的空间。因此，这篇教程选择社区二次开发版本 DSH NEXT，带你从下载安装到首次使用，完整走一遍流程。

如果你是第一次接触 DSH，不需要提前了解 Agent 框架，也不需要自己编译源码。按照下面的步骤操作即可。

> **注意**：DSH NEXT 是社区维护的开源项目，并非 DeepSeek 官方产品。它基于官方 DSH 进行扩展，具体功能和更新节奏以社区项目发布的信息为准。

---

## 一、先了解 DSH NEXT

DSH 的核心是 Agent 运行框架。它通过插件扩展能力，让 AI 不仅能够回答问题，还可以调用工具执行任务。

例如：

- 读取和修改本地文件。
- 执行终端命令。
- 辅助编写和分析代码。
- 通过插件接入更多工具和服务。

DSH NEXT 则是在官方 DSH 的基础上进行二次开发，增加了 Profile 管理、故障恢复、Agents Anywhere 远程控制、Community Market 社区插件市场等功能，同时补充了系统托盘和桌面管理能力。

对于第一次安装的用户，选择 DSH NEXT，可以直接体验这些社区扩展功能。

---

## 二、下载 DSH NEXT

首先打开项目的 GitHub Releases 页面：

**下载地址：**

https://github.com/anywhere-labs/dsh-desktop/releases

进入页面后，找到最新的 DSH NEXT 版本，在 Assets 中选择与你的操作系统和 CPU 架构对应的安装包。

目前提供的安装包主要包括：

| 操作系统 | 下载文件 |
| --- | --- |
| Windows x64 | DSH-NEXT-2.0.21-next-x64-Setup.exe |
| macOS（Intel / Apple Silicon） | DSH-NEXT-2.0.21-next-universal.dmg |
| Linux x64 | DSH-NEXT-2.0.21-next-amd64.deb |
| Linux x64 | DSH-NEXT-2.0.21-next-x86_64.AppImage |
| Linux ARM64 | 对应 ARM64 安装包 |

如果你使用的是普通 Windows 电脑，大多数情况下选择 Windows x64 安装包即可。

如果使用 Mac，可以选择 macOS Universal 版本，它同时支持 Intel 和 Apple Silicon 芯片。

> **下载时注意**：不要直接下载源码压缩包。源码包主要用于开发，不是普通用户直接安装的桌面程序。

---

## 三、安装 DSH NEXT

### 1. Windows 安装

下载 Windows 对应的 `.exe` 安装包。

下载完成后，双击运行安装程序，按照安装向导完成安装。

安装结束后，可以从桌面快捷方式或 Windows 开始菜单启动 DSH NEXT。

如果 Windows 弹出安全提示，先确认安装包来自项目的 GitHub Releases 页面，再根据系统提示处理。

### 2. macOS 安装

下载 macOS 对应的 `.dmg` 文件。

双击打开安装包，将 DSH NEXT 拖入 Applications（应用程序）目录。

完成后，在 Launchpad 或应用程序目录中找到 DSH NEXT 并启动。

如果 macOS 提示无法验证开发者，请先确认安装包来源和项目发布信息，再按照系统的安全设置处理，不要随意绕过来源不明程序的安全限制。

### 3. Linux 安装

如果使用 Ubuntu 或 Debian，可以下载 `.deb` 安装包。

进入下载目录，在终端执行：

```bash
sudo apt install ./DSH-NEXT-2.0.21-next-amd64.deb
```

如果选择 AppImage，则需要先赋予执行权限：

```bash
chmod +x DSH-NEXT-2.0.21-next-x86_64.AppImage
```

然后运行：

```bash
./DSH-NEXT-2.0.21-next-x86_64.AppImage
```

如果使用 ARM64 设备，请下载对应的 ARM64 安装包，不要直接使用 x64 版本。

---

## 四、首次启动

安装完成后，启动 DSH NEXT。

首次运行时，应用需要初始化桌面环境和相关运行组件。等待初始化完成后，就可以进入主界面。

如果启动过程中出现异常，可以先关闭应用并重新启动。如果仍然无法进入主界面，再查看项目文档或使用应用提供的恢复功能。

对于第一次使用的用户，建议先保持默认设置，不需要一开始就调整 Profile、插件市场和其他高级选项。

---

## 五、配置模型

安装好 DSH NEXT 后，还需要配置模型，Agent 才能正常调用模型完成任务。

在配置之前，需要准备一个可用的模型 API。

如果使用 DeepSeek 的模型，可以前往 DeepSeek 开放平台：

https://platform.deepseek.com/

注册并登录后，根据平台提供的流程创建 API Key。

> **提示**：API Key 可以理解为调用模型服务的凭证。请妥善保管，不要公开分享，也不要直接提交到 Git 仓库。

接下来回到 DSH NEXT，在模型配置区域按照界面提示填写对应信息。

通常需要准备：

- **Provider**：模型服务商。
- **API Endpoint**：模型服务接口地址。
- **API Key**：刚刚创建的密钥。
- **Model**：需要使用的模型名称。

填写完成后保存配置，并选择对应模型。

> **注意**：不同模型服务商的 Endpoint 和模型名称可能不同，应以服务商提供的 API 文档为准，不要直接照搬其他平台的配置。

另外，API 调用通常会产生费用，具体价格和额度以模型服务商的计费规则为准。

---

## 六、完成第一次对话

模型配置完成后，可以先尝试一个简单任务，确认 DSH NEXT 是否能够正常调用模型。

例如，在对话框中输入：

```text
你好，请介绍一下你能完成哪些任务，
并说明如何通过插件扩展你的能力。
```

如果能够正常收到模型回复，说明基本的模型连接已经完成。

接下来可以尝试让 Agent 执行更具体的任务。

例如：

```text
请读取当前工作目录，
分析其中的项目结构，
识别项目使用的技术栈，
并总结主要目录的作用。
```

如果 Agent 需要访问本地文件或执行命令，按照界面提示检查并授权相应操作。

> **建议**：第一次使用时先从读取、分析这类低风险任务开始，熟悉工具调用和权限确认流程后，再尝试让 Agent 修改文件或执行命令。

---

## 七、安装完成后，可以继续探索什么？

到这里，DSH NEXT 已经完成首次安装和基础配置。

后续可以根据自己的需求逐步了解其他功能：

- **Profile**：管理不同的工作配置。
- **Community Market**：发现和安装社区插件。
- **Agents Anywhere**：探索跨设备远程操作能力。
- **Recovery**：了解应用出现异常时的恢复方式。
- **桌面设置**：管理系统托盘、桌面偏好和其他应用设置。

> **注意**：部分扩展能力可能需要额外配置或手动启用。例如，新 Profile 中的插件市场、手机远程控制和 Computer Use 并非默认全部开启，具体以当前版本的设置和文档为准。

---

## 八、最后

对于第一次接触 DSH 的用户，整个过程可以概括为：

1. 从 GitHub Releases 下载对应系统的 DSH NEXT 安装包。
2. 按照操作系统完成安装。
3. 首次启动并等待初始化。
4. 配置模型服务商和 API Key。
5. 发起第一次对话，确认模型连接正常。
6. 再根据需要探索插件和其他扩展功能。

DSH 的价值在于让 AI 从单纯的对话工具，进一步具备调用工具和执行任务的能力。

如果你希望体验 DSH 的桌面端功能，同时使用社区提供的扩展能力，可以从 DSH NEXT 开始。
